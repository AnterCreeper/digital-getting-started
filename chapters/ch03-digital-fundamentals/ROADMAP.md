# Chapter 3 Roadmap

## 章节名称

第 3 章：数字电路基础

## 章节 slug

`ch03-digital-fundamentals`

## 先收边界

第三章不能写成“逻辑门名词总表”，也不能写成“半导体器件课缩略版”，也不能提前滑成“标准单元库 / 综合优化导论”。

它真正要解决的是一个更基础的问题：

- 为什么数字抽象在物理世界里成立
- 逻辑功能是怎样从器件和门电路长出来的
- 门电路最后会以什么物理形态落地，而不只是停留在逻辑符号层
- 为什么一旦引入寄存器、时钟和状态，系统语义就变了
- 为什么时序约束、亚稳态和同步边界不是后端细节，而是数字系统成立条件

因此，本章的教学主线不应按“知识点堆放”组织，而应按一条因果链组织：

1. 器件如何支持逻辑抽象
2. 逻辑功能如何组合
3. 状态如何被保存
4. 时钟系统为什么会失效，以及为什么必须被约束

## 章节定位

第 1 章建立了全景地图，第 2 章建立了最小工具闭环。第 3 章要做的，不是继续扩地图，也不是继续堆工具，而是让读者第一次真正进入数字系统的“物理依据 + 结构语义 + 时间语义”三位一体视角。

这里还要额外守住一个新边界：第 3 章正文不能重新膨胀成“半导体物理前置课”。正文只保留数字抽象所需的最小器件直觉；更深一层的能带、载流子、费米能级、漂移/扩散、PN 结与 MOS 电场调制背景，交给附录一 `ap01-semiconductor-physics-intuition` 承担。

本章应被视为整本书的基础承重墙。后续第 4 章 RTL、第 6 章算术电路、第 7 章系统级 RTL，都会默认读者已经具备本章建立的这些直觉：

- 0/1 不是天降符号，而是电路在噪声、阈值和延迟约束下达成的工程抽象
- 组合逻辑与时序逻辑不是两类语法，而是两类完全不同的系统语义
- 寄存器边界决定了系统切分方式，组合逻辑锥决定了时序压力位置
- 建立时间、保持时间、skew、uncertainty、metastability 这些概念不是“背定义”，而是系统可靠性的边界条件
- 门延迟不是一个与环境无关的静态常数；负载、fanout、transition 和级联关系会彼此耦合，并沿整条路径传播

## 为什么不建议做成单讲

如果第三章只做成 1 节 `90 min` 大课，风险不是“内容太多”这么简单，而是会把两类不同层次的问题粗暴拼接在一起：

- 前半节在讲 CMOS、门电路和组合逻辑
- 后半节突然跳到寄存器、状态、setup/hold、亚稳态

学生最后往往会把它听成两门课的压缩包，而不是一条完整因果链。

更合理的做法是 **2 讲**：

1. 第一讲解决“逻辑从哪里来”
2. 第二讲解决“系统为什么会因为时间而失败”

这样既能匹配 `90 min` 课堂节奏，也不会过度切碎章节结构。

## 建议拆分为 2 讲

### `l01-digital-abstraction-comb-logic`

建议标题：

`数字抽象、CMOS 与组合逻辑基础`

本讲任务：

- 让读者把数字抽象和器件层依据真正接起来
- 说明逻辑门不是纯符号游戏，而是由 CMOS 结构实现的工程对象
- 让读者知道逻辑门最后不只会画成晶体管图，还会进一步落成规则化的版图 / 标准单元形态
- 建立从晶体管、反相器、基础逻辑门到组合逻辑的递进关系
- 在组合逻辑层面引入延迟、竞争与冒险的最小工程直觉
- 为后续 logic effort、综合器为何必须考虑 fanout / transition / 路径耦合埋下直觉基础
- 守住正文接口：只讲 MOS 作为受控开关所必需的最小器件直觉，把更深半导体物理内容外包给附录一

必须覆盖：

- 数字抽象为什么成立，以及它依赖什么前提
- MOS 晶体管最小工作直觉：栅控导通、上拉/下拉、NMOS 与 PMOS 分工
- NMOS / PMOS 的切面视角与版图视角：让读者知道器件最后如何落在硅片上
- 线性区 / 饱和区的最小工程直觉：不做公式推导，只说明“MOS 不是理想开关，延迟来自真实器件行为”
- CMOS 反相器结构、输入高低时的导通路径与输出结果
- 反相器的版图视角：为什么它是最基本、最简单、通常也是最快的数字门结构
- 电压传输特性（VTC）、噪声容限、上升 / 下降延迟、充电 / 放电路径、短路电流的直觉性解释
- fanout、transition time 与门延迟之间的耦合关系：说明门延迟不是静态常数
- 环形振荡器：用来说明“延迟不是可忽略细节”
- NAND / NOR 的静态 CMOS 结构，以及最基本的版图视角
- 标准单元的最小视野：逻辑门最终会落成规则化边界的版图单元；同一逻辑功能通常会有不同驱动能力或面积/速度权衡的物理变体，但本讲只点到为止
- AOI / OAI 的存在感只做点名，不作为主线展开
- 传输门的最小认识：它提醒读者数字逻辑不只有静态 CMOS 门这一种组织方式
- 布尔代数、真值表、逻辑表达式与门级结构的互相转换
- 组合逻辑的定义：当前输出只依赖当前输入
- 竞争与冒险的最小例子
- 半加器作为组合逻辑的收束例子；全加器可作为点到为止的扩展例子

内部建议按 4 个模块推进：

1. 为什么数字抽象成立：从器件到反相器
2. 反相器为什么是数字世界的基元：VTC、充放电、短路、噪声容限、fanout / transition
3. 从晶体管图到可实现门电路：NAND / NOR、最小版图视角、传输门
4. 组合逻辑为什么会在时间上出问题：环形振荡器、竞争 / 冒险、半加器 / 全加器

建议时间分配：

- `10 min` 导入：数字抽象与本章路线图
- `30 min` CMOS、反相器、VTC、充放电、噪声容限、fanout / transition
- `25 min` NAND/NOR、最小版图视角、传输门、表达式与门级结构互转
- `15 min` 环形振荡器、竞争与冒险示例
- `10 min` 小结与课堂练习

明确不展开：

- 长沟道模型、精确器件公式推导
- 版图、工艺参数、单元库 characterization
- track、库高度、drive strength、HD / HP / HS 等标准单元库细节：只建立“存在这些物理变体”的视野，不在本讲系统展开
- RTL 建模语法，这些留给第 4 章
- logic effort 的正式量化分析与综合优化策略：本讲只埋“门延迟会沿路径耦合传播”的直觉，后续章节再系统讲
- 能带形成、态密度、费米分布、电子/空穴、`np` 锁定、漂移/扩散、PN 结与 MOS 电容的更深半导体物理因果链：这些转移到附录一

典型工程任务：

- 画出 CMOS 反相器并标出输入变化时的导通路径
- 对照晶体管图和版图示意图，说明反相器 / NAND / NOR 最后会变成什么物理对象
- 从逻辑表达式写真值表并画出门级结构
- 从门级结构反推逻辑表达式
- 给出一个含不同路径延迟的例子，解释毛刺为什么出现
- 画出半加器门级结构，并说明它为什么仍然属于组合逻辑

### `l02-sequential-logic-timing`

建议标题：

`时序逻辑、状态机与时序约束基础`

本讲任务：

- 从“当前输入到当前输出”的组合语义，推进到“状态随时钟演化”的时序语义
- 让读者理解锁存器、触发器、寄存器链和状态机在系统中的作用
- 建立“寄存器边界 + 组合逻辑锥”的观察框架
- 让读者第一次真正理解 setup / hold / skew / metastability 的工程含义

必须覆盖：

- 锁存器、触发器、寄存器、寄存器链的概念与作用
- 组合逻辑 vs 时序逻辑：输出是否依赖历史状态
- 状态机的基本结构（状态寄存器 + 组合逻辑），Moore 机与 Mealy 机的差异点到为止
- 状态寄存器、下一状态逻辑、输出逻辑三者关系
- 从寄存器切分组合逻辑锥的视角看同步系统
- 传播延迟、建立时间、保持时间
- setup violation / hold violation 的直觉图与波形后果
- 时钟偏斜（skew）、时钟不确定性（uncertainty）
- 负载、扇出、transition、rise/fall time 的基本实现含义
- 亚稳态是什么，以及为什么它只能被降低概率、不能被“消灭”
- 时钟域与同步边界的最小概念
- 双触发器同步器的作用边界

内部建议按 4 个模块推进：

1. latch / flop / register / state
2. 同步系统结构与状态机框架（Moore / Mealy 差异点到为止）
3. setup / hold / skew / uncertainty
4. metastability、clock domain 与同步边界

建议时间分配：

- `20 min` 锁存器、触发器、寄存器与状态
- `20 min` 同步系统结构、寄存器边界与组合逻辑锥（Moore / Mealy 差异点到为止）
- `30 min` propagation delay、setup、hold、skew、uncertainty
- `15 min` 亚稳态、同步器、clock domain 边界
- `5 min` 小结与课堂练习

明确不展开：

- 完整 STA 方法学
- 完整 CDC 设计规范
- 状态机编码优化与 RTL coding style，这些放到后续章节

典型工程任务：

- 从简单行为描述中识别哪些部分是状态、哪些部分是组合逻辑
- 画出同步系统的基本结构框图（状态寄存器 + 组合逻辑）
- 在框图中标出状态寄存器、输出逻辑和组合逻辑锥边界
- 分析一个违反 setup 或 hold 的示意波形
- 解释为什么异步输入直接进入寄存器会带来风险

## 章节级叙事主线

第三章最重要的不是“覆盖了多少术语”，而是让读者走完下面这条认知链：

1. 晶体管像受控开关，因此能形成稳定的上拉 / 下拉网络
2. 上拉 / 下拉网络让逻辑门成为可实现对象，而不仅是符号
3. 逻辑门最终会落成版图化、规则化的物理结构，而不只是纸上的门符号
4. 多个逻辑门组合后，系统仍然只是在做“当前输入到当前输出”的映射
5. 但门延迟、负载和 transition 会沿级联关系彼此耦合，因此时间问题从第一讲就已经出现
6. 一旦引入寄存器，系统就拥有了状态，语义从函数变成状态转移
7. 一旦引入时钟，系统是否正确不仅取决于逻辑关系，还取决于时间关系
8. 一旦存在异步输入或跨域边界，数字抽象的前提会被挑战，必须用同步策略管理风险

如果这条链断掉，后面的 RTL、流水线、CDC、综合、STA 都会退化为术语背诵。

- 给出结构图、波形图、时序图

- 更细的术语定义

- 补充例题与工程任务拆解
- 对易混概念做并排比较，例如 latch vs flop、setup vs hold
- 对正文刻意压缩掉的半导体物理背景给出清晰附录接口，而不是把它们重新塞回讲义主线
